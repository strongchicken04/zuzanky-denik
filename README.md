# 🐹 Zuzanky deník — webová aplikace

Útulný deníček s mazlíčkem, který roste s každým zápiskem.
Tohle je automaticky sestavený web (GitHub Pages) — **zdrojový kód žije
v repozitáři `sp500-futures-research` ve složce `zviratkovy-denik`.**

**Adresa aplikace:** https://strongchicken04.github.io/zuzanky-denik/

Na iPhonu: otevřít v Safari → Sdílet → **Přidat na plochu**.
Všechna data (zápisky i fotky) zůstávají jen v telefonu.

Nasazení nové verze: ve zdrojovém repu `node scripts/build-web.mjs`
a obsah `dist/` pushnout sem.
